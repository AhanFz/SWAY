# Product
<!-- impeccable:product-schema 1 -->
## Platform
adaptive
## Stack
React Native, Expo, TypeScript; Gesture Handler and Reanimated. Supabase backend in stage 2. Stack supplied in BUILD-BRIEF.md.
## Users and purpose
People reading short neutral news summaries who want to compare their own reaction with the crowd, without an account.
## Constraints
Good, bad, or skip; responses final. Guessing, personal history, and insights stay on-device. No photos, comments, rewards, demographic breakdowns, daily limits, or web version.
## Previous checkpoint
Stage 1: native card stack with hard-coded stories, gestures, buttons, simulated results and basic recap. Stop for phone testing after this stage, as requested in the build brief. No network votes, anonymity guarantees, or live news in this checkpoint.
## Evidence
User supplied BUILD-BRIEF.md and sway-prototype.html. Prototype content is fixture data, not independently verified news. Crowd totals are simulated.
## Accessibility
Equivalent buttons for all swipes, safe areas, scalable text, readable light/dark themes, screen-reader labels, and reduced motion.

## Current scope
User requested substantive UI redesign and continuation of remaining points. Implementing backend source, guesses, local history/insights, native result sharing, RSS/AI pipeline and attestation. Cloud activation awaits organization/cost confirmation and server credentials. Real-device validation remains required.
